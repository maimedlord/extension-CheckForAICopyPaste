Proofreader settings

Development build: eligible Reddit pastes can display a quiet notice with exact excerpts and Dismiss. Test the sample below before trying a draft.

Detection provider

Default: limited basic checks for standalone explicit placeholders. Contextual detection uses GPT-6 Luna at api.openai.com.

Cloud stays off until you enable it and grant browser permission. Requests use store:false; this does not guarantee zero provider retention.

The key is not synced or saved to disk by this extension. Re-enter it after browser restart or extension reload. Your PowerShell credential is separate.

Sample: “Here is a version you can post. The meeting starts at noon. Let me know if you would like a shorter version.”

Site and input settings

Each domain includes its subdomains. This development build has browser access only to Reddit, regardless of the list.

Characters are counted as Unicode code points. Oversized inputs are skipped, never truncated.
